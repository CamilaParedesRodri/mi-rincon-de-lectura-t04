# mi-rincon-de-lectura-t04
CRUD de biblioteca personal integrado con EPN Event Manager - Taller T.04 de Construcción de Software.

## Ejecutar Mi rincón de lectura

Desde la raíz del repositorio en PowerShell, con Node.js 24 o superior:

```powershell
cd lectura
npm.cmd start
```

Abre [Mi rincón de lectura](http://127.0.0.1:3001) para agregar, consultar, editar o eliminar obras.
El servidor crea la base SQLite en `lectura/datos/lectura.sqlite` al iniciarse.
